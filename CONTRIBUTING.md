# Contributing to msp-outreach-automator

Thank you for considering contributing to this project! 

## How to Contribute
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/gui-interface`).
3. Set up `.env.example` and test your changes locally using mock/test data.
4. Submit a Pull Request with a clear description of your implementation.

## V2 Priority Roadmap
* **Desktop / GUI Interface:** Build a user-friendly graphical front-end around the existing engine logic. Contributors are free to use whichever Python GUI framework they prefer (e.g., CustomTkinter, PyQt, Tkinter, Streamlit, etc.).
* **Terminal Enhancements:** Interactive CLI progress bars or formatted tables (e.g., using `rich`).
* **Dynamic CSV Mapping:** Configurable options to map custom CSV column headers to recipient attributes.
