# Contributing to msp-outreach-automator

Thank you for considering contributing to this project! 

## How to Contribute
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/ui-enhancements`).
3. Set up `.env` from `.env.example` and test your changes locally (`python gui.py` or `python main.py --dry-run`).
4. Submit a Pull Request with a clear description of your implementation.

## V2 Priority Roadmap
* **GUI / Dashboard Enhancements:** Expanding the CustomTkinter desktop interface and integrating job tracking features.
* **Embedded Console:** Routing live execution logs directly into an in-app `CTkTextbox` widget.
* **Dynamic CSV Mapping:** Adding UI options to map custom CSV column headers to recipient attributes.
